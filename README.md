# 🦈 SharkBee MC Avatar Generator

基于 [molanko-avatar-generator](https://github.com/lanlan3292/molanko-avatar-generator) 的网页版头像生成器。

## 功能

- 上传任意图片 → 生成 MC 风格头像
- 支持描边类型：无 / 纯色 / 发光 / 脉冲
- 支持背景类型：无 / 纯色 / 渐变 / 模糊 / 噪点
- 可调描边宽度和颜色
- 可调缩放倍数

## 使用

```bash
npm install
npm start
# 访问 http://localhost:3847
```

## 依赖

- Node.js
- @napi-rs/canvas（自动安装）
